# 🌍 Social Mentor AI

A centralized platform for managing social donations using AI assistance and location-based coordination.

Social Mentor connects donors, volunteers, and NGOs on a single platform to ensure efficient donation collection, delivery tracking, and impact measurement.

---

## 🚀 Problem Statement

Many donors, local businesses, and college communities are willing to contribute essential items such as food, clothes, and toys. However, existing donation systems are:

- Unstructured and manual
- Lacking location-based coordination
- Missing delivery tracking
- Not recognizing volunteer efforts

Social Mentor solves this by providing a smart, organized, and transparent digital platform.

---

## 💡 Features

✅ Role-based users (Donor / Volunteer / NGO)  
✅ Donation creation & tracking  
✅ Location-based coordination  
✅ Gemini AI integration for smart assistance  
✅ Geoapify Maps integration  
✅ Volunteer reward system  
✅ Impact dashboard  

---

## 🔄 Workflow

User → Register → Create Donation → Notify Volunteers → Accept Task → Pickup → Deliver → Earn Points → Track Impact
